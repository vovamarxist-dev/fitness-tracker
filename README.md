# Подход — трекер тренировок (Telegram Mini App)

Тестовая версия (MVP): свой план тренировок, строгий таймер отдыха и рекомендации по весам после тренировки.

## Что умеет
- **Мои планы тренировок** — свои тренировки (дни), упражнения из каталога: подходы × повторы × вес, шаг прибавки,
  отдых между подходами и отдельно между упражнениями.
- **Каталог** — около 190 упражнений на русском, у каждого своя анимация (`src/anim/patterns.ts`). Можно добавить своё.
- **Тренировка** — упражнение, подходы, вес; «Подход выполнен» запускает таймер отдыха: предупреждение за 10 с,
  сигнал на нуле, красный перебор и напоминание каждые 15 с. «Завершить упражнение» — подтверждение подходов.
- **Итоги** — дисциплина отдыха и рекомендации по весам (правила: [docs/progression.md](docs/progression.md)),
  кнопка «Применить к плану».
- Данные хранятся на устройстве (IndexedDB), работает без интернета.

## Разработка
```bash
npm install
npm run dev      # http://localhost:5173
npm test         # тесты правил прогрессии
npm run build    # сборка в dist/
npm run catalog  # пересобрать каталог из scripts/source/free-exercise-db.json
```
Страница со всеми анимациями: `http://localhost:5173/#anims`.

## Доступ только для участников теста
Задайте в GitHub переменную `ALLOWED_IDS` (Telegram ID через запятую). Без неё приложение открыто всем, у кого есть бот.
