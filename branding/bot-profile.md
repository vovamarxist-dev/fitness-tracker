# Оформление бота в @BotFather — тема «Завод»

Тексты, аватар и кнопка меню выставляются скриптом `node scripts/setup-bot.mjs`
(токен в `.env.bot`). Картинку описания Bot API не поддерживает — она загружается вручную:
`/mybots` → бот → **Edit Bot** → **Edit Description Picture** → `bot-cover.png`.

## Описание (437/512)
```
МАШИНА — построй из себя машину.

Машина работает по чертежу, держит режим и с каждой сменой выдаёт больше. Здесь так же:

• Чертежи — свои тренировки из каталога на 200 упражнений с анимацией.
• Охлаждение — таймер держит отдых между подходами и не даёт отвлечься.
• Наладка — после смены подскажет, когда добавить вес, а когда пройти техобслуживание и разогнаться заново.

Данные хранятся только на вашем телефоне.

Жми «Запуск» внизу.
```
