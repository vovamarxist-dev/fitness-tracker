# Оформление бота в @BotFather

Всё делается в @BotFather: `/mybots` → ваш бот → **Edit Bot**.

| Что | Команда | Лимит | Где видно |
|---|---|---|---|
| Имя | Edit Name (`/setname`) | 64 символа | Заголовок чата и список чатов |
| Описание «О себе» | Edit About (`/setabouttext`) | 120 символов | Профиль бота и превью ссылки |
| Описание | Edit Description (`/setdescription`) | 512 символов | Пустой чат до нажатия «Start» |
| Картинка описания | Edit Description Picture | 640×360 | Над описанием в пустом чате |
| Аватар | Edit Botpic (`/setuserpic`) | квадрат | Везде |
| Кнопка меню | Bot Settings → Menu Button | — | Слева от поля ввода |

## Имя
```
Подход — дневник тренировок
```

## О себе (About)
```
План тренировок, строгий таймер отдыха и подсказки, когда добавлять вес. Откройте кнопкой «Тренировка».
```

## Описание (Description)
```
Подход — дневник тренировок прямо в Telegram.

• Составьте свои тренировки из каталога на 190 упражнений с анимацией.
• Держите отдых между подходами: таймер напомнит, если вы отвлеклись.
• После тренировки получите подсказки, когда добавлять вес, а когда откатиться и разогнаться заново.

Данные хранятся только на вашем телефоне.

Нажмите кнопку «Тренировка» внизу, чтобы начать.
```

когда добавим серверную часть (напоминания от бота, поддержка).
