# Оформление бота в @BotFather — «Машина»

Тексты, аватар и кнопка меню выставляются скриптом `node scripts/setup-bot.mjs`
(токен в `.env.bot`). Картинку описания Bot API не поддерживает — она загружается вручную:
`/mybots` → бот → **Edit Bot** → **Edit Description Picture** → `bot-cover.png`.

```

```

## О себе (104/120)
```
Построй из себя машину. Свой план тренировок, жёсткий отдых по таймеру и подсказки, когда добавлять вес.
```

## Описание (396/512)
```
ПОСТРОЙ ИЗ СЕБЯ МАШИНУ.

Без отговорок и без «с понедельника». Только план, вес и дисциплина.

• Составь свои тренировки из каталога на 200 упражнений с анимацией.
• Таймер держит отдых между подходами — не залипнешь в телефоне.
• После тренировки — чёткий ответ, когда добавлять вес, а когда откатиться и пробить заново.

Данные хранятся только на твоём телефоне.

Жми «Погнали» внизу и работай.
```
